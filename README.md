Beginning of My Journey 

My first steps into web development — learning HTML and CSS from the ground up.

 Featured Project: BE HER

Joan.html is a homepage I built for BE HER, a concept for a youth-empowering initiative focused on leadership, mentorship, and career growth for young women.

The page includes a hero intro, a mission section, and a services grid covering Mentorship, Career Empowerment, and Leadership Development — practice in structuring a real, multi-section site with semantic HTML and a linked stylesheet.

What I practiced
Semantic HTML (header, nav, main, section, footer)
Linking stylesheets and images
Building nav bars and content sections
